# 🚦 Simulador de Semáforo

## 📌 Objetivo
Projeto criado para **reproduzir e compreender o fluxo automático e sequencial** de um sistema de semáforo.

### ⚙️ Funcionamento
• Alternância correta entre luzes: 🟢 Verde → 🟡 Amarelo → 🔴 Vermelho  
• Controlo de tempos e troca de estado  
• Lógica de temporização e sequência

## 🛠️ Tecnologias
- HTML5
- CSS3
- JavaScript — **destaque na lógica de tempo e sequência**
